# Project documentation rule

- `docs/USER_GUIDE.md` is the canonical Chinese user guide.
- Any change to user-visible features, UI actions, workflow states, configuration variables, API providers, CLI commands, HTTP endpoints, storage paths, backup/migration steps, costs, safety boundaries, or troubleshooting must update `docs/USER_GUIDE.md` in the same change.
- Keep the user guide written for non-developers and verify commands and paths against the current code.
- Keep the README link to the user guide valid.
